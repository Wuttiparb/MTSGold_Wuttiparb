BOT Daily Exchange-Rate Workflow

This project collects the Bank of Thailand's weighted-average interbank exchange rate for THB/USD and keeps up to 20 daily records in SQLite.

Before the first run

  1. Install Python 3.10+ and uv.
  2. Run uv sync in the project folder.
  3. Copy .env.example to .env.
  4. Enter your applicant name in English and your own API credential from the BOT Exchange Rates portal.
  5. Use the Authorization header shown in the request example and confirm the response field mappings in .env against your portal subscription.

Keep credentials private. Never commit .env or API credentials to GitHub. No API data is bundled with this starter project.

Collect data

Run uv run python bot_api_daily.py. The script requests a 31-day window ending yesterday, stores at most the latest 20 returned dates, and creates the SQLite file under .venv/.

By default, the response mapping expects result.data.data_detail with period and rate fields. If the BOT response differs, set BOT_RECORDS_PATH, BOT_DATE_FIELD, and BOT_RATE_FIELD in .env. Dates must be ISO YYYY-MM-DD.

Run tests

Install the test extra with uv sync --extra test, then run uv run pytest. Tests use sample data and do not call the BOT API.
